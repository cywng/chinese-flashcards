# 点菜通 · Hanzi Menu & Vocab Flashcards

Vibe coded webapp

---


## 🎴 Core Functions & How to Use

### 1. Study Modes
* **📖 Read Hanzi (Default)**: Front shows Hanzi only. Tap card to flip and reveal **Pinyin**, **English**, **Mandarin audio**, and **character-by-character breakdown**.
* **🔊 Audio Hint (Front)**: Tap before flipping to hear the spoken word and test your character recognition.
* **🎯 Recall Mode**: Tap `🎯 Recall Word` on the toolbar to show English first and practice active recall of precise Chinese terms.
* **書 Menu Font Toggle**: Tap `字 Sans` / `書 Menu Serif` in header to toggle between modern UI font and restaurant menu Serif/Songti.

### 2. Deck Toggling (Individual, Lessons Only, Groups)
Tap the **top header pill** or **`[ 🗂️ Deck ▾ ]`** on the toolbar to open the switcher:
* **📖 Lessons Only**: Combines all lesson notes (*Level 9 Lesson 1*, etc.) into one session.
* **🍜 Menus & Dining**: Combines all 5 restaurant/food decks (110 words).
* **🌟 All Decks Combined**: Studies all 147 words across your library.
* **Individual Deck**: Tap any single deck to study it alone.
* **🎛️ Multi-Select**: Tap to check/uncheck any custom combination of decks.

### 3. Paste Custom Vocab
1. Go to the **📋 Paste Vocab** tab.
2. Paste raw characters (e.g. `口水鸡 夫妻肺片`) or delimited lines (`口水鸡 - Spicy cold chicken`).
3. Tap **⚡ Generate Pinyin & Preview** (works 100% offline).
4. Edit any field in the preview table and tap **💾 Save to Deck**.

### 4. Controls & Shortcuts
| Action | Mobile Gesture | Desktop Key |
| :--- | :--- | :--- |
| **Flip Card** | Tap card | `Space` |
| **Again (Repeat)** | Swipe Left | `1` |

| **Prev / Next** | Bottom arrows | `←` / `→` |

## 📱 Install on Phone (Offline PWA)

* **iPhone (Safari)**: Open site → Tap **Share (`⬆`)** → **Add to Home Screen**. *(Ensure physical Silent/Mute switch is OFF to hear audio).*
* **Android (Chrome)**: Open site → Tap **Menu (`⋮`)** → **Install app / Add to Home screen**.
